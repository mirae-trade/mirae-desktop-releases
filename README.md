# Mirae Desktop Releases

Official download repository for Mirae Desktop.

This repository contains release notes, desktop installers, portable builds, and SHA-256 checksum files. The application source code is maintained separately in a private repository.

## Download

Open the [Releases](https://github.com/mirae-trade/mirae-desktop-releases/releases) page and choose the build for your operating system. Verify the provided SHA-256 checksum before installation.

## Security

Only download files published under this repository's official GitHub Releases.
